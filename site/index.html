Every coding agent.
One terminal.

Baton is a terminal workspace for command-line coding agents. Switch harness mid-thread, split a goal across worktrees, and review every change before it ships.

Drives Codex, Claude Code, Cursor, Grok, OpenCode, and Antigravity.

What you get from one window

  • Switch harness without retyping context.

    A returning harness receives only the turns it has not seen. Before a handoff leaves the thread, a preview shows the exact payload. Send it, skip it, or cancel.

  • Run work in parallel, in git worktrees.

    The planner splits a goal into independent tasks. Each worker gets its own branch under baton/<run>/<task>, so two workers can edit the same file without colliding.

  • Gate every worker behind a reviewer.

    The reviewer reads the commit and the implementor's evidence, then returns APPROVE or REQUEST_CHANGES. Only an approved commit can merge.

  • Finish the loop in the same window.

    Review a diff line by line, then commit, push, open a pull request, read its checks, and merge. Every remote action previews its plan and rereads the live state first.

A run, end to end

One prompt becomes a plan, a set of worktrees, a review verdict, and a commit you can ship.

  1. Plan

    The planner returns tasks, each with a harness, a model, and the files it owns. Preview the plan before any worker starts.

  2. Work

    Workers run in parallel in separate worktrees. A task starts after its dependencies finish, and a failed dependency skips its dependents.

  3. Review

    The reviewer tries to falsify the completion claim. A worker waiting for a decision shows up in the inbox, not in a log file.

  4. Ship

    Integrate the approved branches, or open one pull request per worker. Merged work and existing pull requests are skipped, so a retry is safe.

What it asks of you

No account
Baton runs on the harness login or API key you already have.
No telemetry
There is no Baton service in the path. Prompts go to the harness you chose.
No lock-in
Threads, turns, and usage are readable as JSON and over MCP.
One binary
Install with curl, Homebrew, or Cargo. Git and one harness CLI are the only requirements.
